# 更美的敬拜 — 公共崇拜學探討互動式資訊網

**著者：** 易啟年  
**出版：** 榮光出版社／榮光傳道會  
**專案定位：** 建置現代化、響應式的全書互動閱讀平台，提供語音朗讀、全文搜尋、列印及數位典藏功能。

---

## 專案簡介

本專案以易啟年牧師所著的公共崇拜學著作《更美的敬拜 — 公共崇拜學探討》為基礎，規劃建置完整的互動式閱讀網站，涵蓋全書 219 頁內容。

網站支援桌上型電腦、筆記型電腦、iPad、Android 平板及智慧型手機，方便使用者查閱崇拜學的神學基礎、程序編排、事奉人員職責、音樂事工及聖禮規範。

## 核心特色與功能

### 1. 全書內容與原書圖版

- **完整原書圖版：** 收錄第 1 至第 219 頁的原書掃描圖片，保留原始版面。
- **數位排版文字：** 提供全書 OCR 文字，並以原書圖版進行逐頁校對。
- **閱讀設定：** 支援縮小、標準及放大字級，以及亮色、暗色與暖調紙本主題。
- **圖文對照：** 在大螢幕上並排顯示原書圖版與數位文字。
- **圖片縮放：** 支援 125%、150%、175%、200% 及 250% 等放大倍率。
- **快速縮放：** 提供放大、縮小及重設為 100% 的按鈕。
- **操作快捷鍵：** 支援 `+` 放大、`-` 縮小及 `0` 重設。
- **雙擊放大：** 可透過雙擊圖片快速放大或還原。

### 2. 章節樹狀導航

依據原書第 2 至第 7 頁的目錄建置章節導航系統。

- 涵蓋 15 個主要章節、各級小節、作者自序、生平簡介、附註及參考書目。
- 提供獨立的側邊目錄與自訂滾動滑桿。
- 顯示書本頁碼（P.1 至 P.215）及 PDF 頁碼（P.1 至 P.219）。
- 隨閱讀進度同步高亮目前所在的章節。

### 3. 頁碼快速導航

正文下方提供頁面滑動控制器（Page Scrubber）。

- 拖曳滑桿即可快速跳轉至指定頁面。
- 即時顯示目標頁碼與對應章節標題。
- 提供上一頁（`‹`）及下一頁（`›`）按鈕，方便精確翻頁。

### 4. 台灣國語語音朗讀

使用瀏覽器的語音合成技術（Text-to-Speech，TTS）提供朗讀功能。

- 支援台灣中文語系（`zh-TW`）。
- 提供台灣女聲及男聲選項，實際可用聲音依裝置及瀏覽器而定。
- 支援以下朗讀速度：
  - `0.75x`
  - `1.0x`（標準）
  - `1.25x`
  - `1.5x`（快速）
  - `2.0x`（極速）
- 提供朗讀段落高亮與音波動畫，協助使用者追蹤閱讀進度。

### 5. 響應式介面設計

網站依據不同裝置的螢幕尺寸調整介面配置。

**手機介面**

- 自適應頂部導覽列與操作按鈕。
- 按鈕最小尺寸為 40 × 40 px。
- 側邊目錄自動轉換為滑入式抽屜（Drawer）。
- 點擊漢堡選單開啟目錄，選取章節或點擊遮罩後關閉。
- 文字及圖片自適應螢幕寬度。

**平板介面**

- 支援橫向與直向螢幕。
- 提供圖文對照及雙頁閱讀配置。

**桌上型電腦介面**

- 提供完整閱讀工作區。
- 同時呈現章節目錄、正文與搜尋結果。

### 6. 全文即時搜尋

提供全書關鍵字檢索功能。

- 支援搜尋「招待人員」、「詩班」、「聖餐」、「洗禮」等關鍵字。
- 即時顯示符合條件的頁面與搜尋結果。
- 使用 `<mark>` 標記符合條件的關鍵字。
- 點擊搜尋結果即可跳轉至對應頁面。

### 7. 列印功能

提供適合研讀與保存的列印方式。

- 列印目前頁面。
- 列印目前章節。
- 選擇數位排版文字或原書掃描圖版。
- 使用 `@media print` 設定專用列印樣式。
- 列印時隱藏不必要的控制按鈕及側邊工具列。

### 8. Web Audio 音效引擎

透過瀏覽器的 Web Audio API 即時合成音效，不必載入外部音效檔案。

預計支援的音效包括：

- 紙張翻頁聲。
- 按鍵回饋音。
- 設定切換提示音。
- 語音朗讀啟動提示音。

### 9. 顯示與操作設定

透過頂部導覽列的「顯示與操作設定」開啟設定視窗，提供七大設定項目。

1. **全螢幕模式：** 開啟或關閉沉浸式閱讀。
2. **音效回饋：** 開啟或關閉操作音效，並保存使用者偏好。
3. **裝置排版：** 自動、手機、平板或電腦寬屏。
4. **版面配置：** 自動、直式滾動或橫式雙頁閱讀。
5. **介面語言：** 繁體中文或英文。
6. **文字字級：** 縮小、標準或放大。
7. **視覺色系：** 跟隨系統、亮色雅緻、暗色沉浸或暖調紙本。

### 10. 本機運行與部署

- 避免依賴外部圖床及 CDN，降低外部資源失效的風險。
- 網站資源以本機檔案為主。
- 可部署至 GitHub Pages，提供線上瀏覽服務。
- 實際運行方式須配合 JavaScript 模組、資料載入方式及瀏覽器安全限制進行測試。

## 本地運行方式

1. 使用檔案總管或 Finder 開啟專案資料夾。
2. 嘗試使用 Google Chrome、Microsoft Edge、Safari 或 Firefox 開啟 `index.html`。
3. 測試閱讀、搜尋、翻頁、朗讀及列印功能。

**注意：** 若網站使用 JavaScript ES Modules、`fetch()` 或其他受到瀏覽器本機檔案安全政策限制的功能，直接開啟 `index.html` 可能無法正常運作。遇到此情況時，請改用本機 HTTP 伺服器進行測試。

## GitHub 部署教學

### 第一步：初始化 Git 並提交檔案

在專案根目錄開啟終端機，執行以下指令：

```bash
git init
git add .
git commit -m "feat: Initial release of Better Worship"
```

### 第二步：推送至 GitHub

先在 GitHub 建立一個新的空 Repository，名稱設為 `Better-Worship`，再執行：

```bash
git branch -M main
git remote add origin https://github.com/USERNAME/Better-Worship.git
git push -u origin main
```

請將 `USERNAME` 替換成自己的 GitHub 使用者名稱。

如果已經設定過遠端倉庫，請先執行 `git remote -v` 確認設定，避免重複新增 `origin`。

### 第三步：啟用 GitHub Pages

1. 開啟 GitHub 上的 `Better-Worship` Repository。
2. 點擊 **Settings**。
3. 在左側選單中點擊 **Pages**。
4. 在 **Build and deployment** 區域設定：
   - **Source：** Deploy from a branch。
   - **Branch：** `main`。
   - **Folder：** `/ (root)`。
5. 點擊 **Save**。
6. 等待部署完成，並依照 GitHub Pages 顯示的網址開啟網站。

網站網址通常會採用以下格式：

```text
https://USERNAME.github.io/Better-Worship/
```

部署完成後，即可透過網址在手機、平板與電腦上瀏覽網站。
